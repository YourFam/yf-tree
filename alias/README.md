# yf-git-tree

Unscoped alias of [`@yourfam/yf-tree`](https://www.npmjs.com/package/@yourfam/yf-tree). Same command (`yf-tree`), same version.

npm will not publish unscoped `yf-tree` (too similar to existing `rc-tree`). This name is the `npx` stand-in.

```bash
npx yf-git-tree --help
```

Install the scoped package if you can; this name exists so `npx yf-git-tree` cannot be taken by someone else.
